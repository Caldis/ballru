# BALLRU · 环爆模拟

零依赖、单文件的"小球撞击粒子环 + 镜头无限缩小"**放置×roguelite** 弹球模拟。

**在线游玩:<https://caldis.github.io/ballru/>**,或双击 `index.html` 离线玩,无需安装任何东西。

发光主球在同心粒子环内自动弹跳,每次撞击造成伤害、奏出上行音阶并产出星尘;
环被打穿后整环碎裂(慢动作 + 冲击波 + 低频轰炸),镜头拉远进入更大的下一环。
环越深,粒子护甲越厚——用星尘升级伤害与技能,推得更深,或引爆**超新星**转生换取核心。

## 核心循环(放置 × 成长 × 对抗)

```
撞击 → ✦星尘 → 商店升级(伤害/技能)→ 推进更深的环
                                   ↓
   ◉核心 ← 超新星转生(RING 10+) ← 深环粒子护甲指数成长(墙)
```

- **对抗机制**:粒子血量按环深指数成长(×1.22/环);装甲粒子(3 倍血)、**治愈者**(给邻居回血,建议点击优先点杀)、黄金粒子(8 倍星尘)
- **挂机友好**:零操作自动战斗;星尘按伤害比例持续入账(+N/min 实时可见);**离线收益**按星尘速率结算(上限 8 小时)
- **选择权**:每次破环获得一次**三选一本局强化**(不暂停、可排队、1/2/3 键速选)
- **转生**:RING 10 后可引爆超新星,核心提供全局星尘 +10%/个、球速 +2%/个

## 六大技能(涌现之源)

| 技能 | 效果 |
|---|---|
| ⟁ 穿甲弹 | 撞击概率波及相邻粒子 |
| ⌁ 雷暴 | 撞击计数触发链式闪电 |
| ☄ 流星雨 | 击飞的粒子化作流星,流星再撞碎粒子 → **链式雪崩** |
| ◉ 引力井 | 点击布设引力井:吸聚后爆裂 |
| ⇌ 相位跃迁 | 撞墙概率瞬移到环对侧穿行 |
| ✦ 点金术 | 星尘获取加成 |

## 操作

| 按键 | 功能 |
|---|---|
| `ESC` | 菜单(商店 / 设置 / 统计 / 存档) |
| `空格` | 暂停(启动画面 = 开始) |
| `1` `2` `3` | 选择破环强化卡 |
| `R` / `N` | 重开(同种子)/ 换种子 |
| `C` | 高级调参控制台(31 项实时参数) |
| `H` | **录屏模式**:隐藏全部 UI(保留 COMBO 与横幅) |
| `S`(按住)/ `M` | 慢动作 / 静音 |
| 点击画面 | 冲击脉冲(有引力井技能时 = 布井) |

## 存档

- localStorage 自动保存(每 10 秒 + 破环 + 关闭页面),含**局内进度续玩**
- 菜单 → 存档管理:导出/导入 base64 存档码、危险区清空
- 「今日种子」:按日期生成种子,全球同关

## 调参控制台(TUNER)

`C` 键打开:物理/世界/镜头/视觉/音频/系统 6 组 31 项参数全部实时生效,双击恢复默认;
4 个预设(默认爽/混沌风暴/禅模式/超频狂暴);参数 JSON 复制/导入;截图 PNG;
同 `seed` + 同参数 = 完全可复现(录引流视频可反复重录同一局)。

## 技术要点

- Canvas 2D + Web Audio API 全合成音频(零外部资源)
- 廉价 Bloom(1/3 + 1/9 离屏层 additive 叠加)/ 远景环 `setLineDash` 圆点 LOD
- trauma² 震屏 / 子步进物理防隧穿 / 带种子的确定性随机(渲染抖动与 gameplay RNG 隔离)
- 伤害制战斗:粒子 HP / 类型 / 治愈再生,分桶 Path2D 批量绘制
- 调试句柄:控制台 `BALLRU.*`(world / meta / dust(n) / supernova…)

设计文档见 `docs/superpowers/specs/`。
