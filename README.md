# BALLRU · 环爆模拟

零依赖、单文件的"小球撞击粒子环 + 镜头无限缩小"病毒式弹球模拟。
**双击 `index.html` 即可游玩**,无需安装任何东西。

发光主球在同心粒子环内高速弹跳,每次撞击打飞一颗粒子并奏出上行音阶;
环被打到阈值后整环碎裂(慢动作 + 冲击波 + 低频轰炸 + 震屏),镜头拉远进入更大的下一环,无限循环。

## 操作

| 按键 | 功能 |
|---|---|
| `空格` | 暂停 / 继续(启动画面时 = 开始) |
| `R` | 重开(同一种子,可复现同一局) |
| `N` | 换随机种子重开 |
| `C` | 收起 / 展开调参控制台 |
| `H` | **录屏模式**:隐藏全部 UI(保留 COMBO 与横幅) |
| `S`(按住) | 手动慢动作 |
| `M` | 静音 |
| 点击画面 | 冲击脉冲:推开主球并击碎附近粒子 |

## 调参控制台(右侧 TUNER 面板)

- 所有参数实时生效;**双击参数行恢复默认值**。
- 标 `◆` 的参数(环几何类)修改后自动重建世界,**保留进度与分数**。
- 四个预设:🔥 默认爽 / 🌪 混沌风暴(粒子穿击 + 10 球)/ 🧘 禅模式 / ⚡ 超频狂暴。
- `复制参数` 导出 `{seed, P}` JSON;`导入参数` 粘贴后一键复现任何人的"完美一局"。
- `截图 PNG` 直接下载当前画面(含特效,不含 DOM 面板)。

### 参数分组速览

- **物理**:球速 / 破环增速 / 反弹散射 / 重力 / 碰撞模式(`实墙弹射` 节奏感最强;`粒子穿击` 可从缺口钻出,更混沌)/ 球数上限与分裂周期
- **世界**:首环半径 / 环间距 / 粒子大小与密度 / 整环碎裂阈值 / 色相起点与步进
- **镜头**:取景留白 / 缩放跟随速度 / 震屏强度 / 慢动作倍率与时长 / 连击里程碑顿帧
- **视觉**:光晕 / Bloom 辉光 / 拖尾长度 / 火花数量 / 星空密度 / 漂浮分数 / HUD
- **音频**:主音量 / 音阶(五声、大调、小调、布鲁斯、都节)/ 音符衰减 / 空间回声 / 低频轰炸 / 氛围铺底
- **系统**:点击脉冲开关与力度 / 自动降质(帧率不足时自动降低特效)

## 录屏 / 引流视频工作流

1. 调好参数(或导入一套参数 JSON);
2. 按 `H` 进入录屏模式(隐藏面板与统计,保留 COMBO 和 `RING n SHATTERED` 横幅);
3. 用任意录屏工具(OBS / Win+Alt+R)录制;
4. 同一 `seed` + 同一参数 = 完全可复现的同一局,可反复重录。

## 技术要点

- Canvas 2D + Web Audio API 全合成音频(零外部资源,离线可玩)
- 廉价 Bloom:场景另渲染到 1/3 与 1/9 分辨率离屏层,放大后 additive 叠加
- 远景环 LOD:`setLineDash` 圆点虚线近似粒子环,无限缩小不掉帧
- trauma² 震屏模型 / 子步进物理防隧穿 / 带种子的确定性随机
- 音高沿所选音阶随连击上行,碰撞按横向位置做声像(StereoPanner)
