# BALLRU · 环爆模拟

零依赖、单文件的"小球撞击粒子环 + 镜头无限缩小"**放置×roguelite** 弹球模拟。

**在线游玩:<https://caldis.github.io/ballru/>**,或双击 `index.html` 离线玩,无需安装任何东西。

发光主球在同心粒子环内自动弹跳,每次撞击造成伤害、奏出上行音阶并产出星尘;
环被打穿后整环碎裂(慢动作 + 冲击波 + 低频轰炸),镜头拉远进入更大的下一环。
环越深,粒子护甲越厚——用星尘升级伤害与技能,推得更深,或引爆**超新星**转生换取核心。

## 核心循环(放置 × 成长 × 对抗)

```
撞击 → ✦星尘 → 商店升级(伤害/技能)→ 推进更深的环
                                   ↓
   ◉核心 ← 超新星转生(RING 10+) ← 深环粒子护甲指数成长(墙)
```

- **对抗机制**:粒子血量按环深指数成长(×1.22/环);装甲粒子(3 倍血)、**治愈者**(给邻居回血,建议点击优先点杀)、黄金粒子(8 倍星尘)
- **挂机友好**:零操作自动战斗;星尘按伤害比例持续入账(+N/min 实时可见);**离线收益**按星尘速率结算(上限 8 小时)
- **选择权**:每次破环获得一次**三选一本局强化**(不暂停、可排队、1/2/3 键速选)
- **转生**:RING 10 后可引爆超新星,核心提供全局星尘 +10%/个、球速 +2%/个
- **◉ 核心熔炉**:核心消费的长线乘数——星尘奇点 / 起源之力 / 时间晶体(离线上限至 32h)/ 流星核心
- **🏆 成就**:12 个成就(百连击/越狱/流星雨夜/黄金猎手…),统计页查看

## 环形态(v3/v4)

- **圆点 / 线条 / 尖刺**:粒子环三种几何形态,随种子分布
- **弧线刃环三变体**:单层旋转 / **双层反向旋转** / **呼吸开合**(缺口周期性张合)——经典"旋转圆环逃脱"形态全家桶
- **缺口真穿透**:对最近粒子做精确弧距判定,缺口直接穿出(再无隐形墙);球可在环间游走
- **逃逸即坍缩**:所有球越过的环在身后爆碎;每次穿缺口有星尘奖励 + `ESCAPE!` 提示——钻空子就是爽点
- **`碰撞体积%` 参数**(调参台·物理):全局缩放碰撞判定(0.3~1.5,默认 0.8)。调低 = 球更容易钻缝、逃逸大量发生;调到 1+ = 严格物理

## 音乐模式(v4)

调参台/设置 → 旋律模式:撞击逐音符演奏旋律,**撞得越快歌越快**。
内置公版旋律:小星星 / 欢乐颂 / 卡农 / 茉莉花 / 致爱丽丝;
**自定义简谱**:`1-7` 音级、`+`/`-` 升降八度、`#` 升半音,如 `1 1 5 5 6 6 5`,设置页粘贴即用并持久化。

## 🎰 LUCKY SPIN 老虎机(v5)

柏青哥式三转轮,与"三选一"机制平行的**高上限随机奖励**:

- **触发**:击碎场景中的**幸运币粒子**(彩虹脉动,出现概率在调参台·世界 `幸运币概率%` 调节);或击破 **Boss 环**(`Boss环周期` 可调,击破必触发)
- **Boss 三型**(种子决定):**壁垒**(整环一条血)/ **激光**(旋转光束击退球并打断连击)/ **分裂**(半血相变为双高速旋刃,可击杀也可钻缺口)
- **保底**:连续 N 次未中三连,下一转必出三连(`老虎机保底` 参数,默认 8,0=关;触发时红灯+"保底触发"播报)
- **演出**:跑马灯边框、三转轮模糊渐停、**リーチ听牌**(前两轮同符号时第三轮拉长+心跳)、点击转轮可提前停、对子/三连发光、**777 JACKPOT** 全屏闪光+慢镜+横幅;多次触发自动排队连转
- **奖励模型**(7 符号,对子/三连/安慰奖三档,随环深缩放):星尘雨 / 狂暴(伤害×2~4 限时)/ 流星风暴 / 雷暴超载 / 分裂+球 / 核心◉ / 幸运 7;**777 = 核心+8、巨额星尘、全增益 18s**
- 限时增益显示在 HUD 右上,倒计时临期闪烁

## 存档

## 调参控制台(TUNER)

`C` 键打开:物理/世界/镜头/视觉/音频/系统 6 组 31 项参数全部实时生效,双击恢复默认;
4 个预设(默认爽/混沌风暴/禅模式/超频狂暴);参数 JSON 复制/导入;截图 PNG;
同 `seed` + 同参数 = 完全可复现(录引流视频可反复重录同一局)。

## 技术要点

- Canvas 2D + Web Audio API 全合成音频(零外部资源)
- 廉价 Bloom(1/3 + 1/9 离屏层 additive 叠加)/ 远景环 `setLineDash` 圆点 LOD
- trauma² 震屏 / 子步进物理防隧穿 / 带种子的确定性随机(渲染抖动与 gameplay RNG 隔离)
- 伤害制战斗:粒子 HP / 类型 / 治愈再生,分桶 Path2D 批量绘制
- 调试句柄:控制台 `BALLRU.*`(world / meta / dust(n) / supernova…)
