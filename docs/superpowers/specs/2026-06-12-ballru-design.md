# BALLRU — 病毒式弹球环爆模拟 设计定稿

日期:2026-06-12
状态:用户已预先授权全部设计决策("增添你认为一切能爽能火的元素"),本文档为实现依据。

## 1. 一句话定义

一个零依赖、单文件、双击即玩的网页弹球模拟:发光主球在同心粒子环内高速弹跳,每次撞击打飞一颗粒子并奏出上行音阶;环被打到阈值后整环碎裂(慢动作 + 冲击波 + bass drop + 震屏),镜头平滑拉远进入更大的下一环,无限循环。附带完整的实时调参控制台,并支持一键隐藏全部 UI 的录屏模式。

## 2. 爽感配方(设计主轴)

1. **积累→释放循环**:撞击声沿五声音阶逐级上行(积累紧张感)→ 环碎瞬间 sub-bass drop + 和弦 + 慢动作(释放)。
2. **即时多通道反馈**:每次撞击同时给出 音符 + 火花爆裂 + 撞击光圈 + 微震屏 + combo 数字弹跳。
3. **尺度升级感**:镜头持续拉远、环越来越大、粒子越来越多、主球越来越快、每 2 环分裂一颗新球。
4. **确定性物理**:无随机失控,带种子的 RNG,可复现"完美一局"。

## 3. 核心机制

- **世界**:中心 (0,0),同心环 i 半径 `R = base + i·gap`,每环粒子数按周长/间距计算,色相按环递进。环无限程序化生成。
- **主球**:恒速运动(速度 = 基础速度 × 环数增益),撞击粒子后镜面反弹 + 可调随机抖动。
- **墙体两模式**(控制台切换):
  - `solid`(默认):未碎裂环视作连续圆墙,主球触及环半径即径向反弹,并击飞撞点角度最近的存活粒子。节奏可控,积累感最强。
  - `pellet`(混沌):逐粒子圆-圆碰撞,可从被打出的缺口穿出,更接近原始病毒视频的"撞出去"感。
- **环碎**:存活粒子比例 < 阈值(默认 30%)→ 剩余粒子全部爆飞、冲击波扩散、全屏闪白、慢动作(timeScale 0.15→1 缓动)、trauma 震屏、主球提速、镜头 zoom out 至下一环。
- **多球**:每碎 2 环分裂一颗新球(上限可调,默认 4)。
- **Combo**:撞击间隔小于窗口则 combo++,决定音高爬升与分数倍率;断连重置。里程碑(25/50/100…)触发琶音和弦 + hit-stop。
- **交互**:点击/触屏 = 在点击处释放脉冲冲击波,推开主球并击飞附近粒子(可关)。

## 4. 视觉

- 深空底色 + 两层视差星空(世界空间,随镜头缩放产生纵深)。
- 全部发光体用 additive(`lighter`)双层绘制(光晕 + 实核),禁用 shadowBlur(性能)。
- **廉价 bloom**:发光层另绘制到 1/3 分辨率离屏 canvas,放大后 additive 叠加,强度可调可关。
- 主球白核 + 彩色光环 + 渐隐折线拖尾(世界空间历史点);被击飞粒子短拖尾。
- 撞击:火花粒子、扩散光圈、漂浮 +分数。环碎:全屏冲击波环 + 闪白 + vignette 脉冲 + 中央大字 `RING n SHATTERED`。
- **trauma 震屏系统**:trauma 累积、shake = trauma²,偏移 + 旋转噪声,随时间衰减。
- HUD 全部 canvas 绘制(录屏干净):SCORE 滚动数字、COMBO 大字(随热度变色)、RING/BALLS 计数、当前环剩余进度条。

## 5. 音频(Web Audio 全合成,零资源文件)

- 信号链:voices → feedback delay(空间感)→ master gain → compressor。
- 撞击:双 osc pluck(微 detune),音高 = 所选音阶[combo 步进],默认五声音阶(任意顺序皆和谐)。
- 环碎:sub-bass 滑落(110→40Hz)+ 噪声爆 + 上行 sweep + 根三五和弦。
- 可选 ambient pad(低音量,默认开,音量 8%)。
- 启动遮罩("点击开始")同时解决 AudioContext 手势解锁。

## 6. 调参控制台(硬需求)

- **schema 驱动**:所有参数集中在一个带 `{min, max, step, default, group, label, rebuild?}` 的 schema 表,控制台 DOM 自动生成——加参数 = 加一行 schema。
- 右侧毛玻璃霓虹面板,分组折叠:预设 / 物理 / 世界 / 镜头手感 / 视觉 / 音频 / 工具。
- 控件:滑杆(实时数值,双击恢复默认)、开关、下拉、按钮。
- **预设**:🔥 默认爽 / 🌪 混沌风暴 / 🧘 禅模式 / ⚡ 超频狂暴。
- **工具**:暂停、重开、随机种子、截图 PNG 下载、参数 JSON 复制/导入。
- 标记 `rebuild` 的参数变更后软重建世界(保留分数)。

## 7. 快捷键

Space 暂停 · R 重开 · C 收起/展开控制台 · H 隐藏全部 UI(录屏模式)· S 按住慢动作

## 8. 性能预算

1080p@60fps:物理只计算活动环 ±1;视口外环粒子跳绘;飞散粒子/火花有上限并 swap-remove 回收;fillStyle 缓存;DPR 上限 2;可选自动降质(帧耗持续超标时自动降 bloom 与火花)。

## 9. 技术栈与交付物

零依赖单文件 `index.html`(Canvas 2D + Web Audio + 原生 DOM 控制台)+ `README.md`。
验证:Playwright 实测(启动→运行→截图→console 零报错→控制台交互)。

## 10. 明确不做(YAGNI)

排行榜、移动端虚拟摇杆、WebGL shader 后处理、外部音频资源、多人模式。

# v2 追加设计:放置 × 成长 × 对抗(2026-06-12)

## 背景问题

v1 是纯正反馈循环:破环 → 加速+分裂 → 更快破环,约 10 分钟后画面被无限小球与高速消环刷爆,进入不可玩状态。

## 解法:三层结构

1. **对抗(墙)**:粒子带 HP,按环深指数成长(baseHp = 1.22^(i−2));撞击改为伤害制。
   粒子类型:普通 / 装甲(3×HP,2×星尘)/ 治愈者(每 0.5s 给 ±3 邻居回 2% 血,玩家须优先点杀)/ 黄金(8×星尘,3% 出现)。
   失控抑制:破环增速默认 7%→3%,环速度乘数封顶 ×2.4。
2. **成长**:✦星尘(按伤害比例持续产出 → 挂机收益平滑可见)买永久升级:
   冲击强化(伤害 ×1.35^lvl,对抗 1.22^i 的墙)/ 引擎超频 / 多重球 / 裂变催化 / 连击窗口 / 离线星核。
   六技能:穿甲弹 / 雷暴(闪电链)/ 流星雨(击飞粒子二次撞击 → 涌现连锁)/ 引力井 / 相位跃迁 / 点金术。
   ◉核心:RING≥10 可超新星转生,gain = ⌊(rings−8)^1.5⌋,每核心 +10% 星尘 +2% 球速。
3. **选择权(非阻塞)**:每次破环积累一次"三选一"本局强化(锋锐/增殖/雷暴扩容/流星潮/点金潮/过载/引力坍缩/连击护盾/裂变/时滞领域),游戏不暂停,可排队(≤3),1/2/3 键速选,录屏模式下隐藏。

## 基础设施

- 主菜单 = 启动遮罩扩展:开始/继续上局/今日种子(日期种子全球同关)/商店/设置/统计/存档管理;游戏中 ESC 呼出(暂停)。
- 存档:localStorage `ballru.save.v2`,自动保存(10s + 破环 + beforeunload/visibilitychange),含局内快照(seed/环数/分数/球数)续玩;base64 存档码导出导入;双击确认清空。
- 离线收益:dustRate(每秒窗口 EMA)× 离线秒数(≤8h)× (30%+14%/离线星核级) × 点金倍率,回归时菜单内结算卡领取。
- 设置页(玩家版,白名单持久化):音量/音阶/震屏/画质/光敏闪光开关/点击脉冲/漂浮分数/HUD/氛围音 + 高级 TUNER 入口。
- 调试句柄 `window.BALLRU`(测试与高级玩家)。

## 验证结论(Playwright 实测)

商店购买/技能触发(178 次流星目击、闪电、引力井)/选牌(池按已购技能过滤、队列、快捷键)/存档跨刷新还原/续局快照/超新星 +8◉/离线 2h → ✦193,547 结算,全部通过;HP 墙生效(12s 破 1 环 vs v1 同期 3-5 环);全程零 console 报错;57fps 为测试窗口 60Hz 垂直同步上限,非引擎瓶颈(同引擎 120Hz 窗口实测 120+)。

# v3 追加设计:碰撞重构 × 环形态 × 鼠标三技 × 核心熔炉(2026-06-12)

## 1. 碰撞重构(修"隐形墙")

旧 solid 模式把未碎环当连续圆墙,炸出缺口球也无法穿出。重构为**角度窗口检测**:
撞击角附近(±球角宽)有存活粒子才径向反弹并结算伤害;否则**穿透**(向外穿出记「越狱」)。
球可在环间游走——`radialBounce` 按球在内/外侧取法线方向,所有未碎环都参与碰撞。
**逃逸即坍缩**:每帧检查所有球的最小包含环,被全体球越过的环自动 shatter(每帧最多一环,演出错开)。
平衡自洽:缺口要靠点击/引力井炸开,其伤害同样受 HP 墙约束——深环炸不动,无法白嫖进度。

## 2. 环形态

- 粒子环三种几何:圆点(填充)/ 切向线条 / 径向尖刺(描边,lineCap round),分布 47/14/19%,前 3 环固定圆点。
- **弧线刃环(18%)**:2-4 段旋转弧(rotSpeed ±0.07-0.24 rad/s),分段 HP(≈baseHp×8-15),受击闪白,段崩解沿弧撒碎片,全段尽碎触发整环 shatter。脉冲/引力井可按角度范围炸弧段。雷电/流星/治愈不作用于弧环。

## 3. 鼠标三技

左键点按=脉冲/布井(<180ms);**左键按住=持续牵引场**(球群被拉向光标,引导穿缺口的核心操作,可调力度);**右键=斥力爆**(球+碎片推开)。按住时画收拢虚线准星;contextmenu 已拦截。

## 4. 核心熔炉与成就

◉ 消费升级:星尘奇点(×1.25/级)/ 起源之力(伤害 ×1.2/级)/ 时间晶体(离线上限 8→32h)/ 流星核心(帧预算 8→28)。
12 成就(meta.ach),关键事件处 checkAch(),解锁横幅+toast,统计页列表展示。新计数器:meteorKills/goldKills/escapes。

## 5. 修复

- **wipeSave/importSave 被 beforeunload 自动存档覆盖**:reload 前先置 suppressSave 旗标——此前"清空存档/导入存档"实际无效,本波修复并实测验证。

## 验证(v3 Playwright)

形态分布抽样 36 环(arc 19%/dot 47%/dash 14%/spike 19%);人工炸 60° 缺口 → 球穿出(escapes=1)→ 弃环坍缩 → 「越狱」成就解锁;弧环受击 hpSum 60→46 且持续旋转;按住牵引把球速 vy +353 拉到 −594;右键斥力、核心熔炉购买、清空存档(修复后)全部通过;全程零 console 报错。

# v4 追加设计:逃逸手感 × 音乐模式 × 弧环变体 × 移动端(2026-06-12)

## 1. 逃逸手感重做(用户反馈:逃逸过难,钻空子=爽感来源)

旧实现用"索引窗口"找最近粒子——窗口内有任何粒子就反弹,从不量真实距离,缺口须 ≥5 颗粒子宽。
重做为**精确弧距判定**:球心到最近存活粒子的弧距 ≤ (球r+粒r)×`P.hitbox` 才反弹,否则穿过。
新参数 **`碰撞体积%`**(0.3~1.5,默认 0.8,持久化):统一作用于 solid 弧距 / pellet 圆碰撞 / 弧环 pad 与厚度。
调低 → 单颗粒子缺口即可穿越、甚至能钻完整墙的粒子缝;调高 → 严格物理。
逃逸奖励:星尘(8×环深×倍率)+ 60 分 + `ESCAPE!` 漂浮 + 双音上行音效 + 火花。
实测(hitbox 0.8):3 颗粒子缺口 15s 内穿出 6 次、连锁坍缩 4 环(旧版 9 颗缺口都难穿)。深环仍受 HP 墙约束(开洞要磨血),早期狂欢、后期收敛。

## 2. 音乐模式

简谱解析器(`#?[1-7][+-]*`,`0`/非法 token 跳过),内置公版旋律(小星星/欢乐颂/卡农/茉莉花/致爱丽丝)与自定义简谱(设置页 textarea,持久化)。
`audio.hit` 在旋律模式下逐音符推进(melodyPtr),撞得越快歌越快;自由音阶模式保持原 combo 上行逻辑。重开时指针归零。

## 3. 弧环三变体

`segGeom(ring, seg) → [起始角, 弧长, 半径]` 统一几何:层偏移(dR)/反向旋转(dir)/呼吸缩放(breath 频率 + 相位)。
变体 roll:40% 单层 / 30% 双层反转(两层各 2-3 段,dR=±1.7r,旋向相反)/ 30% 呼吸开合(弧长 0.16~1.0 倍周期张合)。
碰撞、渲染、范围伤害、碎片位置全部走 segGeom;ring.band 加宽外层预筛。

## 4. 移动端

双指点按=斥力爆(touchIds 计数);viewport 禁缩放;面板 touch-action:pan-y;选牌卡换行+小屏 CSS;tap-highlight 清除。

## 验证(v4 Playwright)

变体抽样 16 种子:单层 4/双层 4/呼吸 3;小星星解析 42 音(首 8 音 semitone 正确)且实战推进 126 音符;3 粒缺口 15s 穿 6 次;双指斥力改变球速;hitbox/旋律/自定义简谱跨刷新持久化;全程零 console 报错。
